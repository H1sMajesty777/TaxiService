# Служба такси

Учебный проект команды ЭФБО-09-24 по дисциплине «Программирование корпоративных систем». Вариант 34 по таблице РТУ МИРЭА, основная сущность — заказ поездки.

| Работа | Проект | Связь с базой |
| --- | --- | --- |
| КР № 1 | [Консольная система на Java](kr-01/README.md) | Схема PostgreSQL, тестовые данные и доступ через JDBC |
| КР № 2 | Настольное приложение на JavaFX | Прямое JDBC-подключение к PostgreSQL из КР № 1 |
| КР № 3 | Сервер на Spring Boot с REST API и веб-интерфейсом | Схема КР № 1 служит основой для миграций Flyway |

В репозитории реализована КР № 1. Для КР № 2 и № 3 предусмотрены отдельные папки на следующих этапах.
