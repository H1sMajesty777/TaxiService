Готовые файлы для передачи находятся в локальной папке `delivery`. Архив `taxi-variant34-source.zip` содержит файлы Git и отчёты. Файл `taxi-variant34-debug.apk` прикладывается отдельно. Настоящие секреты хранятся в личном `.env`, а для запуска у проверяющего служит скрипт и пример настроек.

## Порядок показа на защите

1. Поднять стек и открыть health, затем запустить КР 1 и КР 2. Показать общую таблицу заказов.
2. Провести [сквозной сценарий](ARCHITECTURE.md#один-заказ-во-всех-четырёх-работах) от консоли через JavaFX и веб до заметки в Android.
3. Показать роли веб-клиента на двух учётных записях, конфликт версий, архив и восстановление.
4. Продемонстрировать CSV preview/apply на [учебном файле](../kr-03/examples/ride-import.csv), графу приоритета и запись аудита.
5. Перезапустить Android-приложение, дождаться восстановления сессии, затем выйти.
6. Открыть [объяснение проекта](ARCHITECTURE.md#подготовка-команды) и распределить вопросы между выступающими.
