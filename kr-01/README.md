# КР № 1. Служба такси

Вариант 34, группа ЭФБО-09-24. Консоль диспетчера хранит в PostgreSQL пассажиров и заказы поездок. Из меню можно оформлять поездки, обновлять статусы, искать и сравнивать заказы, смотреть статистику и выгружать данные в Excel.

[Условие КР № 1](https://online-edu.mirea.ru/mod/assign/view.php?id=933003) · [Разбор проекта для защиты](docs/README.md) · [ER-диаграмма](docs/er-diagram.svg) · [Пример выгрузки Excel](docs/ride-orders.xlsx)

## Запуск

Понадобятся JDK 21, Apache Maven 3.9+ и одна из двух сред ниже. Проверьте, что `mvn -v` показывает Java 21. Выполняйте команды из папки `kr-01`.

### PostgreSQL через Docker Compose

Откройте Docker Desktop и дождитесь запуска движка. На Linux подойдет Docker Engine с плагином Compose.

```sh
docker compose up -d --wait
mvn -q compile exec:java
```

Compose создаёт базу `taxi` и загружает схему и учебные данные при первом создании тома. Приложение подключается к `127.0.0.1:5434`. Команда `docker compose down` останавливает контейнер. Именованный том хранит заказы между запусками.

На Windows для общей базы, запущенной из корня репозитория, используйте `..\scripts\Start-TaxiConsole.ps1` из папки `kr-01`. Скрипт включает UTF-8 для русских букв и знака ₽ и загружает параметры из корневого `.env`.

### Свой PostgreSQL

Войдите под администратором в отдельный учебный экземпляр PostgreSQL и создайте базу. Пример для новой роли и базы на порту 5432.

```sh
psql -h 127.0.0.1 -U postgres -d postgres
```

```sql
CREATE ROLE taxi LOGIN PASSWORD 'taxi_local';
CREATE DATABASE taxi OWNER taxi ENCODING 'UTF8' TEMPLATE template0;
\q
```

Примените оба скрипта в новой пустой базе в указанном порядке. `psql` попросит пароль роли `taxi`.

```sh
psql -h 127.0.0.1 -p 5432 -U taxi -d taxi -v ON_ERROR_STOP=1 -f sql/01-schema.sql -f sql/02-demo-data.sql
```

Укажите адрес вашей базы и запустите приложение. SQL-файлы сохранены в UTF-8. При другом клиентском кодировании задайте `PGCLIENTENCODING=UTF8` перед запуском `psql`.

```powershell
$env:TAXI_DB_URL = 'jdbc:postgresql://127.0.0.1:5432/taxi'
$env:TAXI_DB_USER = 'taxi'
$env:TAXI_DB_PASSWORD = 'taxi_local'
mvn -q compile exec:java
```

В Bash используйте `export TAXI_DB_URL='jdbc:postgresql://127.0.0.1:5432/taxi'` и аналогично задайте остальные переменные при отличающихся значениях. Без переменных приложение берет настройки Compose. Если запускаете Maven вручную в PowerShell, включите UTF-8, чтобы терминал мог отобразить и кириллицу, и знак ₽.

```powershell
chcp 65001
[Console]::InputEncoding = [Text.UTF8Encoding]::new()
[Console]::OutputEncoding = [Text.UTF8Encoding]::new()
mvn -q compile exec:java
```

В IntelliJ IDEA можно открыть `pom.xml` как Maven-проект, выбрать JDK 21 и запустить класс `ru.mirea.taxi.Main`. Параметры базы для локальной установки задаются в конфигурации запуска.

## Сквозной пример работы диспетчера

1. Откройте `2 → 3`. Введите пассажира `1`, адрес подачи `ул. Лесная, 5`, адрес назначения `м. Сокол`, дату `2026-11-28 15:30`, стоимость `690,50`. В новой базе заказ получит ID `11`. В повторном запуске используйте ID, который напечатала программа.
2. Введите `4 → 11` в подменю заказов. Оставьте ID пассажира, оба адреса и дату через Enter. Введите новую стоимость `710,50`. Пункт `2 → 11` покажет обновлённый заказ.
3. Выберите `5 → 11 → 4`, чтобы попробовать сразу завершить заказ. Сервис сообщит о запрещённом переходе. Затем выполните `5 → 11 → 2` для подтверждения, `5 → 11 → 3` для начала поездки и `5 → 11 → 4` для завершения.
4. Попробуйте удалить завершённый заказ через `6 → 11 → да`. Получите отказ. Чтобы показать успешное удаление, создайте второй заказ и удалите его в статусе «Новый». Введите `нет`, если хотите сначала показать отмену удаления.
5. Выйдите в главное меню. Статистика покажет 11 заказов, 4 завершённых и 2560,50 ₽. Повторите экспорт и найдите заказ № 11 в Excel. После перезапуска запись останется в базе.

Для проверки ошибок отдельно попробуйте `2 → 2 → abc`, затем `2 → 999999` из подменю заказов. При создании заказа можно передать неизвестного пассажира, одинаковые адреса или нулевую стоимость. При вводе `2026-02-30 09:00` консоль остановит заполнение формы сообщением о дате. После каждого отказа можно выбрать другой пункт в текущем меню.
